DSH Colab Bridge

A personal, single-user integration that connects DeepSeek Harness to the Google Colab API through the official Colab MCP server.

What this is

DSH Colab Bridge is a self-hosted desktop tool. It runs locally on the owner's own computer and connects to https://colaboratory.googleapis.com/mcp so that an AI agent can create Colab runtimes and execute Python code inside them.

Who uses it

The application is used by its owner only. There is no sign-up, no multi-user access, and no public service. The Google OAuth client behind it is registered as a desktop application and is never distributed.

What it does with the Google account

It requests a single Google scope, https://www.googleapis.com/auth/colaboratory, in order to create, run, and delete Colab runtimes that belong to the account holder. Nothing is read from, or written to, any other Google service.

Data handling

OAuth credentials stay on the owner's machine, in the local file %USERPROFILE%\.dsh\local\colab-mcp\token.json. No data is transmitted to any third-party server beyond Google's own API endpoints. See the privacy policy for details.
