Privacy Policy

DSH Colab Bridge · last updated 25 November 2026

Scope

DSH Colab Bridge is a personal desktop application used by a single individual. It is not a public or commercial service and it has no other users.

What is collected

The application collects no analytics, no telemetry, and no personal profiles. The only credential it stores is a Google OAuth 2.0 refresh token issued to the account holder, together with its OAuth client identifier and secret.

Where data is stored

All credentials are stored locally on the owner's computer, in the file %USERPROFILE%\.dsh\local\colab-mcp\token.json. They are never uploaded to, or mirrored by, any server operated by the author of this application.

How data is used

The stored credential is used for exactly one purpose: to obtain a short-lived Google access token so the application can call the Google Colab API (https://colaboratory.googleapis.com) on the account holder's behalf. That is the only Google service contacted.

Third parties

No data is shared with, or sold to, any third party. Requests go only to Google's own API endpoints. There are no advertising, tracking, or analytics providers involved.

Retention and deletion

The credential is retained until it is deleted. It can be removed at any time by deleting the token file above, and the Google-side authorisation can be revoked at myaccount.google.com/permissions. Revoking access there invalidates the stored refresh token immediately.
